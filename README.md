# Pureline Style

Pureline is an opinionated coding style focused on linear control flow, explicit intent, compact formatting, small units, clear ownership, and cohesion over arbitrary size limits.

Read the [code style guide](docs/code-style/README.md) for shared rules and language-specific profiles for Java, JavaScript, TypeScript, React, Go, Crystal, Emerald, Emvus, Novus, and Rust.

The guide is split into Markdown files by topic and language. All rule IDs and examples come from the [Pureline Specification 1.6](PURELINE_SPECIFICATION_1.6.md), the versioned reference.
